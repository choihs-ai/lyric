# Kinetic Lyric Motion

음원과 가사만 넣으면 곡을 분석해서 키네틱 타이포그래피 가사 영상을 만들어 주는 웹 엔진.

**열기:** https://choihs-ai.github.io/lyric/

## 쓰는 법
1. 음원 파일 선택 → 박자·킥·구간·분위기·보컬 자동 분석 (음원 파일이 없으면 유튜브 링크를 넣거나 곡 길이만 넣고 소리 없는 영상으로 만들기 — 유튜브는 공식 플레이어로 재생만 하고 내려받지 않아요)
2. 가사 붙여넣기 — `Intro` / `Verse 1` / `Pre-Chorus` / `Chorus` / `Hook` / `Bridge` / `Verse 2 - 이름` / `Outro` 구간 제목 (`[Chorus]`, `Chorus:`, `후렴` 형식도 인식), `*강조*`, `**최대 강조**`, `(추임새)`
3. 아트 디렉션 확인 (BRUTAL · NEON · EDITORIAL · POP · LO-FI · CINEMATIC) — 자동 추천 / AI 디렉터 / 직접 선택
4. 자동 싱크(베타) 또는 탭 싱크로 줄 타이밍 맞추기 (한 번 하면 저장) — 아무 줄부터 다시 탭, 되돌리기, 0.75배속, 줄별 ±0.05초 미세 조정
5. 영상으로 저장 — 지원되는 브라우저는 재생 없이 곡 길이보다 빠르게 MP4로 만들고, 아니면 재생하면서 녹화

가사는 이 저장소에 들어가지 않고, 입력한 기기 안에만 저장됩니다. 곡마다 프로젝트로 따로 저장되고(음원 포함), 파일로 내보내 다른 기기에서 불러올 수 있어요. 화면 언어는 한국어/English를 고를 수 있어요.

## 개발
`src/`를 고치고 `python3 build.py` → `node tools/smoke.js`. 자세한 구조는 `CLAUDE.md`.
